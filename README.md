# 国内期货手续费 · 保证金实时计算网站

一个纯前端（HTML/CSS/JS）实现的国内期货手续费与保证金实时计算网站，功能参照「交易星球」期货手续费/保证金列表页。

## 快速使用

**双击 `start.bat`** 即可在默认浏览器打开主页面（或者直接双击打开 `index.html`）。

> 无需安装任何软件、无需后端服务。实时行情直接调用东方财富公开行情接口（支持跨域）。

## 功能

- ✅ 覆盖 **上期所、郑商所、大商所、广期所、能源中心、中金所** 六大交易所\n- ✅ **只显示主力合约 / 显示所有合约** 一键切换：默认 85 个主力合约；点击「显示所有合约」拉取全部合约月份（约 800+ 个），每个品种按成交量自动标注主力
- ✅ 每行显示：合约名称/代码、现价、成交量、买/卖开保证金%、保证金金额（元）、开仓/平昨/平今手续费、开+平费用、每跳毛利、每跳净利、主力标记
- ✅ **实时行情**：价格、成交量每 10 秒自动刷新（东方财富 push2 公开接口，CORS 全开）；行情断开时自动降级为本地缓存数据并提示
- ✅ 手续费两种计算方式：**固定元/手**（如 5元）与**按成交金额万分之 X**（如 万分之1）
- ✅ **平今免费**红色标注
- ✅ **保证金 + 手续费计算器**：可选合约、手数、价格（随行情自动更新/可手动改）、保证金加收 %、手续费加收 %，实时算出手续费与保证金
- ✅ 搜索（按名称/代码）、按交易所筛选
- ✅ 默认按成交量降序排列
- ✅ **下载 Excel**：一键导出全部合约手续费/保证金 CSV（Excel 可直接打开，含 BOM 中文不乱码）
- ✅ 手续费收取方式说明弹窗
- ✅ 独立**期权手续费一览表**页（68 个品种，含开/平/平今/行权手续费，上期所/郑商所期权平今免收红色标注）

## 如何更新数据

### 修改手续费 / 保证金
打开 `js/data.js`，每个合约一行，字段说明（文件内有注释）：

| 字段 | 含义 |
|---|---|
| `name` | 合约名称 |
| `code` | 合约代码（如 rb2610） |
| `exch` | 交易所 id：shfe/czce/dce/gfex/ine/cffex |
| `price` / `volume` | 初始价格/成交量（会被实时行情覆盖） |
| `margin` | 交易所标准保证金（%） |
| `mult` | 合约乘数 |
| `tickValue` | 每跳盈亏（元）= 最小变动价位 × 合约乘数 |
| `feeType` | `"fixed"` 固定元/手；`"rate"` 万分之 X |
| `open` / `closePrev` / `closeToday` | 开仓 / 平昨 / 平今手续费（fixed 为元/手，rate 为万分之 X） |
| `isMain` / `remark` | 主力标记 / 备注 |

### 修改期权手续费
打开 `js/options-data.js`，直接改 `open/closePrev/closeToday/exercise` 数值即可。

### 行情来源
- 主通道：`https://push2.eastmoney.com/api/qt/ulist.np/get?secids=...`（实时行情）
- 备用通道：`https://push2delay.eastmoney.com/api/qt/ulist.np/get?secids=...`（延迟行情，约 15 分钟，更稳定）
- 页面每 15 秒自动刷新；主通道连续失败会自动切换到备用通道并显示“延迟行情已连接”
- 各交易所市场代码：上期所 `113`、郑商所 `115`、大商所 `114`、广期所 `225`、能源中心 `142`、中金所 `220`
- 如需更换行情源，修改 `js/app.js` 中的 `QUOTE_HOSTS` 即可

## 重要说明

- 表中为**交易所标准**手续费与保证金，期货公司通常会在交易所基础上**加收一定比例**（可用页面计算器的“加收 %”模拟）
- 实际费率请以你所在期货公司为准
- 行情数据来自东方财富公开接口，可能有延迟，仅供参考
- **期货交易有风险，入市需谨慎**



## 开户广告如何改成你的信息

顶部横幅、右下角悬浮按钮和开户弹窗都是占位信息，改 `index.html`：
- 微信号：把 `你的微信号` 全部替换成你的微信号（按钮的 `data-copy-wechat` 属性）
- 二维码：把 `id="adQr"` 图片的 `src` 换成你的二维码图片路径

## 源码保护与维护说明

- `js/` 下的 JS 是**压缩混淆版**（已删除注释和缩进，降低被直接复制读懂的几率）
- **可读源码备份在 `_src/` 文件夹**（含 `_src/js/*.js` 可读版、`_src/style.css`、`_src/minify.ps1` 压缩脚本）
- 以后要改数据/功能：编辑 `_src` 里的可读版 → 重新运行 `_src\minify.ps1` 生成压缩版 → 刷新页面
- 页脚已加版权声明（index.html / options.html）
- ⚠️ 说明：静态网页源码无法 100% 防盗，压缩混淆只能挡住“顺手抄”；核心数据为交易所公开标准，无保密价值
